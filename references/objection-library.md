# Objection Library

The doubts that stop a cart. Shoppers rarely say them out loud; they just leave.

Use this to decide **which** objections to answer. Answer only the ones that
apply - a page anticipating eight objections reads like a page with eight
problems.

## The universal five

Almost every product carries some version of these:

1. **Will this work for me?** (fit, compatibility, skill, space)
2. **Will it last?** (durability, warranty)
3. **What if it doesn't?** (returns, guarantees)
4. **Is it worth the price?** (value justification)
5. **Is this claim real?** (proof, credibility)

## Category-specific objections

### Apparel & footwear

| Objection | Honest answer shape |
| --- | --- |
| Runs small / large | "Runs small - size up if you're between sizes." State it plainly. |
| Will it shrink? | Give the actual fabric behavior and wash instruction. |
| Sheer / see-through | Name the GSM or lining. |
| Fit on my body type | Give the model measurement **and** the garment measurement. |
| Color accuracy | "Shooting light shifts the grey toward warm; the swatch is closest." |

Answering "runs small" honestly costs some carts and saves the returns
that eat the margin. Say it.

### Electronics

| Objection | Honest answer shape |
| --- | --- |
| Compatible with what I own? | List exact models/ports/protocols. |
| Battery reality | Give hours under stated conditions, not "long life." |
| Firmware / updates | State support window if known. |
| Does it need an app / subscription? | Say so if it does. |
| Warranty length | State it. |

### Beauty & skincare

| Objection | Honest answer shape |
| --- | --- |
| Will it irritate my skin? | Name what it excludes (fragrance, alcohol, essential oils). |
| How long until results? | Give the honest timeline; never promise an outcome. |
| Sensitive / acne-prone safe? | Only claim what testing supports - see compliance redlines. |
| Texture / finish | Describe it sensorially; that is the actual doubt. |

### Home & furniture

| Objection | Honest answer shape |
| --- | --- |
| Will it fit my space? | Give dimensions **and** a reference ("fits a standard 60" alcove"). |
| Assembly required? | State it, with realistic time. |
| Delivery / access | State curbside vs. room-of-choice if known. |
| Care / cleaning | Give it; people fear ruining expensive things. |

### Food & consumables

| Objection | Honest answer shape |
| --- | --- |
| Allergens | State them plainly. |
| Shelf life / storage | Give it. |
| Servings / portions | Convert to a real number. |
| Sourcing claims | Only what is verified - see compliance redlines. |

### Tools, gear, outdoor

| Objection | Honest answer shape |
| --- | --- |
| Tough enough for my use? | Name the use case it is rated for, and the one it is not. |
| Weight / packability | Give real numbers. |
| Replacement parts / serviceability | State it if it exists - it is a trust signal. |
| Warranty | State it. |

### Auto parts & accessories

| Objection | Honest answer shape |
| --- | --- |
| Fits my vehicle? | Give year/make/model coverage explicitly. |
| Install difficulty | State DIY vs. professional. |
| Will it void warranty? | Only state what is verifiable. |
| Durability in weather | Name the rating (IP, UV, salt-spray) if tested. |

## How to answer

**Shape:** name the fear → give the fact → state what it means for them.

> "Runs small. If you're between sizes, size up - the knit has 2% elastane and
> relaxes about half a size after the first wash."

**Placement:**

- **One or two objections** → weave into an existing bullet. Do not break the
  scan for them.
- **Three or more** → a short labeled "Good to know" note after the bullets.
- **Sizing/fit** → near the CTA, because that is where the hesitation peaks.

**Tone:** factual, not defensive. "Runs small" beats "designed for a tailored
fit." Shoppers read defensiveness as a warning.

## What not to do

- Do not invent reassurance you cannot back (extended warranties, certifications,
  "dermatologist tested" without a source).
- Do not answer objections nobody has; it plants doubts.
- Do not bury a real limitation in the Details block and hope.
- Do not use objections as a place to sell harder. Answer and move on.

## Sourcing real objections

When available, mine them from:

1. Return reasons (best signal you can get)
2. Customer service transcripts
3. Review text - especially 3-star reviews, which are specific
4. "Questions" sections on the existing page
5. Competitor page Q&A

If none of that is available, use this library to pick the two or three the
category reliably carries, and flag in "Notes to merchant" that real objection
data would improve the page.
