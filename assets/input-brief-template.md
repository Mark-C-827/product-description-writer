## Gap triage

When something is missing, use this order:

| Missing | Action |
| --- | --- |
| Spec source | **Stop.** Do not write. Ask for the spec sheet. |
| Target customer | Ask one question: "who is this for, and what are they trying to get done?" |
| Brand voice | Infer from category, ask **one** calibrating question, flag the assumption. |
| Objections | Use the category defaults in `references/objection-library.md`; flag that real return data would sharpen it. |
| Proof / certs | Omit the claim entirely. Never imply. |
| Price | Write the page without price references. |

## The one-detail rule

If the spec list is thin, ask for **one** detail - the one competitors omit.
Not a list of ten questions. One.

Good one-detail questions, by category:

- Apparel: "What is the fabric weight and does it shrink?"
- Electronics: "What is the battery life under <realistic condition>?"
- Beauty: "What does it deliberately exclude?"
- Home: "What are the exact dimensions and does it need assembly?"
- Food: "What is the serving count and the allergen list?"
- Tools: "What is the material spec and what is it rated for?"
