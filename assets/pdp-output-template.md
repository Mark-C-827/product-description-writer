# PDP Output Template

The deliverable shape. Fill and ship as one paste-ready block, followed by the
"Notes to merchant" section.

Copy the block below. Comments in `<!-- -->` are instructions, not output -
remove them before delivering.

---

```
## Lead hook

<one line - the transformation or job-to-be-done, not the category>

## Intro

<2-3 sentences. Each under 20 words. Hook -> context -> setup for the bullets.>

## Benefit bullets

- **<bold payoff, 2-4 words>** - <mechanism>, <spec from source>.
- **<bold payoff>** - <mechanism>, <spec>.
- **<bold payoff>** - <mechanism>, <spec>.
- **<bold payoff>** - <mechanism>, <spec>.   (4th and 5th optional)

## Good to know           (include only if there are real objections to answer)

- <objection> - <honest, specific answer>
- <objection> - <honest, specific answer>

## CTA

<one line restating the benefit - never a bare command>

## Details

| Spec | Value |
| --- | --- |
| <label> | <value with unit> |
| <label> | <value with unit> |
```

---

## Section rules

| Section | Rule |
| --- | --- |
| Lead hook | ≤ 25 words. Survives alone as a search snippet. |
| Intro | 2-3 sentences, each ≤ 20 words. No origin story. |
| Benefit bullets | 3-5. Bold payoff in the first 2-4 words. One idea each. Spec-backed. |
| Good to know | 2-4 lines. Only real objections. Omit the section if empty. |
| CTA | Restates the benefit. Never "Buy now". |
| Details | Every literal number from the source. No marketing language. |

## Notes to merchant (always appended)

Do not skip this. It is where the risk lives.

```
### Notes to merchant

**Specs dropped**
- <spec> - dropped because <no buyer benefit / redundant / unverifiable>

**Claims I could not support**
- <requested claim> - not supported by the source. Used instead: <compliant alternative>

**Assumptions to verify before publishing**
- <assumption> - verify <what>
```

## Delivery format

1. The copy block, clean, no commentary inside it.
2. `Notes to merchant` immediately after.
3. Nothing else. Do not add a preamble explaining what you did - the merchant
   can read the copy.

If the source was too thin to write from, say that in one line **instead** of
the copy, and name the single detail you need. Do not deliver thin copy padded
with adjectives.
